# PPS Contact Management System (Real-Life C Project)

A complete Semester 1 Programming for Problem Solving (PPS) C application providing a menu-driven address book with file persistence, structure record management, and string search capabilities.

## PPS Concepts Integrated
* **Structures (`struct`)**: Grouping contact attributes (Name, Phone, Email).
* **File Stream Operations (`fopen`, `fprintf`, `fscanf`)**: Persistent storage on local disk.
* **String Comparison (`strcmp`)**: Targeted record searching and deletion filters.
* **Menu-Driven CLI Loops**: Infinite runtime loops controlled by `switch-case` blocks.

## How to Compile & Run
```bash
gcc main.c -o contact_system
./contact_system
